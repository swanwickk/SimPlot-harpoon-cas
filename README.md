# SimPlot 鱼叉·海上指挥推演存档工具 — 使用说明

## 这是什么？

一个让 AI 直接操作 **SimPlot2**（桌面尺规海战兵棋绘图工具）存档文件的技能包。它破解了 SimPlot2 的存档格式（`.SpScn` 混淆编码 + `.json` 明文），并内置了 **Harpoon V（鱼叉）** 与 **Command at Sea（海上指挥）** 运动规则，使你能够：

- 用自然语言或表格命令，让 AI 自动生成剧本、推进回合、绘制单位运动轨迹
- 不需要手动操作软件界面——AI 直接读改写存档文件，你在软件里打开即可看到结果
- 同时支持水面舰艇、**潜艇**（水上/静航/非静航）与**飞机**

## 能生成什么？

| 输入 | 输出 |
| --- | --- |
| 一段剧本说明（兵力/时间/位置） | `<剧本名>.json` 初设存档 + `舰船信息表-<剧本名>初设.md` |
| 舰船信息表（填写计划航速/航向） | 推进后的新存档 + 新舰船信息表（含实际航向航速） |
| 自然语言指令（"推进一个战术回合，XX右转60度"） | 新存档 `<存档名>-<时间>.json` |
| 任意已有存档 | 按指令修改后的新存档（不覆盖原档） |

自动处理：坐标换算（海里）、转向（前冲/分段/渐进式）、加减速（尺寸等级 A/B/C/D）、转向航速损失、潜艇水下固定转向参数（300码/1节，急舵200码/2节）、静航 50% 加减速、轨迹点写入、Do/Next 回合状态等全部规则。

## 生成的文件如何使用？

### 1. 存档文件（.json / .SpScn）

- 把 AI 输出的 `.json` 文件放入 SimPlot2 的 **Scenarios 目录**（如 `SimPlot2-3 beta 19\Scenarios\`）。
- 在 SimPlot2 中打开该场景即可看到单位、轨迹、时间。
- **保存一次**后，软件会自动生成对应的 `Blue.SpScn` / `Red.SpScn`（AI 只改 json 即可，无需手动处理另外两个）。
- 每个回合输出**新文件**（文件名含回合时间），旧档保留，可随时对比回退。

### 2. 舰船信息表（.md）

推演的"命令板"，Markdown 表格，用文本编辑器或直接在本对话中填写：

```
| 舰船名称 | 尺寸 | 最大速度 | 当前速度 | 当前航向 | 计划航速 | 计划航向 |
| 沙恩霍斯特 | A | 31 | 11 | 150 | 加速 | 右转60° |
```

- **初设表**：AI 生成剧本时自动附带，你只需填"尺寸"（A/B/C/D）和"最大速度"两列。
- **计划表**：每回合推演后 AI 输出新表，你在"计划航速/计划航向"列填下回合命令（支持：加速/减速、加速5节、具体航速如 25；右转30°、左转90°、直接指定航向如 200，空白=直行）。
- **潜艇表**（剧本有潜艇时自动附加）：列 = 潜艇名称/尺寸/最大速度/当前状态/当前速度/当前航向/当前深度/计划状态/计划航向/计划速度/计划深度。状态填 **水上**（深度只能0）、**静航** 或 **非静航**（都在水下，深度>0）；新建默认静航，静航加减速为正常 50%。
- **飞机表**（剧本有飞机时自动附加）：列 = 飞机名称/尺寸/最大速度/当前状态/当前速度/当前航向/当前高度/计划状态/计划航向/计划速度/计划高度。飞机状态改变完全按你的指令，不做校验。
- 填好后交给 AI，AI 校验（转向损失、能力上限、可达性、最小角度转向）并生成新存档。

## 在新电脑上如何复刻？

1. **安装本 skill**：把 `SimPlot鱼叉海上指挥推演` 文件夹放入 `~/.workbuddy/skills/` 目录（用户级，所有项目可用）。
2. **告知 AI 存档目录**：操作时告诉 AI 你的 SimPlot2 `Scenarios` 目录路径即可，例如"存档目录是 D:\games\SimPlot2\Scenarios"。
3. **Python**：需要 Python 3（脚本只用标准库，无需安装任何第三方包）。
4. 完全离线可用，不依赖 SimPlot2 软件运行——AI 直接编辑存档文件。

## 常见问题

- **为什么只改 json 不改 Blue/Red.SpScn？** 软件保存时会自动从 json 派生这两个文件，手动改反而可能不一致。
- **能玩非鱼叉的兵棋吗？** 能。《SimPlot存档文件编写指南.md》是**纯格式文档**（不含鱼叉规则），编辑存档本身适用于任何尺规兵棋；鱼叉规则只在需要计算移动时启用。
- **存档坐标为什么那么大？** 文件里是"海里×100000"的定点数，软件显示时自动换算，无需担心。
